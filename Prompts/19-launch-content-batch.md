# PHASE 19 — LAUNCH CONTENT BATCH

**Prerequisites:** Phase 11 and Phase 14 complete. The Phase 04 editorial plan sets the topics.
**Produces:** the real published content the site launches with.
**Do not:** fabricate, scrape, or lightly reword content from other sites.

## Why this phase exists

The original plan built a publishing workflow but never produced any content. A workflow does not create a site. An empty site cannot be QA tested meaningfully, cannot be assessed for performance under realistic content, and cannot be submitted to AdSense.

This phase exists to populate PromptAtlas with the content defined in Phase 04, following the Phase 14 SOP.

## Step 1: Plan the batch

Using `CONTENT_STRATEGY.md`, produce a specific publishing plan:
- The exact prompts to create, by topic cluster and priority
- The collections they will form
- The target count, per the Phase 01 launch definition
- The order of work

Cover every category defined in Phase 04 well enough that no category archive is a thin page. A category with two entries is a liability, so either fill it or remove it and record that change.

## Step 2: Produce the prompts

For each prompt, work through the Phase 14 SOP in full. Each one needs:
- A descriptive, unique title
- Genuinely useful prompt text that you would defend as good
- An original explanation of what it does and when to use it, in the Phase 07 brand voice
- Accurate categories and tags
- Usage and customization notes where they help
- Alt text if a featured image is used

Quality over count. Twenty prompts that are genuinely useful are worth more than a hundred filler entries, for readers, for ranking, and for AdSense review. If the Phase 01 target is unrealistic at this quality bar, say so and recommend a revised number rather than padding.

Where a prompt is a widely known technique rather than an original creation, say so in the explanation and add real value through the explanation, the structure, and the context. Do not present common knowledge as proprietary.

## Step 3: Run the originality check

Apply the Phase 14 originality process to every prompt before publishing. Report:
- What was checked and how
- Any prompt rejected or rewritten, and why
- Any prompt where originality could not be confidently established, and your recommendation

Do not skip this because the content was written in this session. Content generated from training data can still closely match a published source.

## Step 4: Build the collections

Create the real collections planned in Phase 04, using the Phase 11 mechanism. Each needs an original introduction that justifies the grouping and a deliberate order.

Verify the internal linking actually works across the real content set, and report any orphaned prompt with no collection and no internal links pointing to it.

## Step 5: Fill the content gaps

With real content in place, check and fix:
- Every category and tag archive has enough content to be worth indexing
- Every prompt has at least one internal link pointing to it
- The homepage featured and recent sections show real, good content
- Search returns sensible results for the obvious queries in this content set
- The Phase 09 alias list covers the vocabulary this content actually uses

## Step 6: Schedule the ongoing pipeline

Fill in the Phase 14 content calendar for the weeks after launch, so publishing continues rather than stopping at launch day.

## Verification

With the real content loaded, verify and report:
- Every published prompt renders correctly, with formatting preserved
- Copy works on a sample across the batch, with multi-line formatting intact
- Every collection renders and its links resolve
- No category or tag archive is empty or near-empty
- Search covers the content set sensibly
- Pagination works across the real volume
- Performance still meets the Phase 15 budgets at this content volume, re-measured rather than assumed
- The sitemap includes everything it should

## Completion report

Report the exact number of prompts and collections published, the categories covered and their counts, the originality check results including anything rejected, the re-measured performance figures, the content gaps that remain, and your honest assessment of whether the content set is strong enough for an AdSense application.
